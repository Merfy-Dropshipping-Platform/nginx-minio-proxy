# Раздача витрин новых тем

nginx 1.31.3 с модулем njs: отдаёт магазины новой темы из хранилища — по указателю «магазин → живая сборка» и таблице
раздачи этой сборки. Свой образ рядом с прокси нынешних магазинов (корень репозитория): их конфиги и роутеры эта папка
не трогает. Объекты в хранилище пишет пакет `@merfy/storefront-storage` в site-gen, проработка —
`merfy-mcp/docs/plans/storefront-shell/05-storage-pointer/design.md`.

## Команды

Из этой папки; зависимости — `pnpm install --ignore-workspace` (выше по дереву лежит workspace корня merfy).

- `pnpm test`, `pnpm test:coverage` — правила раздачи (`njs/route.js`) в Node, порог покрытия — 80 %;
- `pnpm stack:up`, `pnpm stack:stop` — стенд `compose.test.yml`: MinIO на 19000, подставной рисовальщик на 18082,
  раздача на 18081;
- `pnpm test:serve` — раздача целиком на стенде;
- `pnpm probe` — проба на стенде: время ответа, память под таблицы, промахи, замёрзшее хранилище;
- `pnpm lint`, `pnpm format:check`.

## Как отвечает

1. Метка хоста (`scarf.merfy.ru` → `scarf`) → указатель `storefront/pointers/<метка>.json`. Указателя нет — 404.
2. Таблица раздачи живой сборки `storefront/routes/<магазин>/<сборка>.json` раскладывается в общую память nginx один раз
   на сборку, строка на путь (≈ 512 байт).
3. Строка пути:
   - файл — из `storefront/blobs/` по отпечатку через кэш nginx; тип, кэш, `ETag` и `Last-Modified` — из строки, у
     браузера тот же отпечаток — 304;
   - переезд — 301 на новый адрес, параметры запроса остаются;
   - удалённое — 410 страницей 404 темы до даты из таблицы, потом 404.
4. Строки нет (промах):
   - адрес без «/» на конце, а со «/» он есть — 301 туда;
   - адрес есть в списке дорисовок сборки `storefront/drawn/<магазин>/<сборка>.json` — файл из него;
   - адрес есть в списке адресов сущностей `storefront/entities/<магазин>.json` — рисовальщик (`/_draw`);
   - иначе — 404 страницей 404 темы, а если её нет в сборке — встроенным текстом.
5. Рисовальщик рисует одну страницу. Одинаковые промахи склеиваются в один вызов, ответы 200 и 404 nginx помнит минуту.
   Вызовов — не больше `DRAW_RATE_SHOP` на магазин и `DRAW_RATE_ALL` на всю раздачу. Молчит дольше `DRAW_TIMEOUT`,
   упёрся в лимит или живая сборка собрана другой версией — 503 с `Retry-After: 5`.
6. Указатель, таблицы и списки nginx держит в кэше «1s» — это одна-две секунды. Хранилище не отвечает — последняя копия
   из кэша, без неё — 503 через 2 с.
7. Файл ключа IndexNow `/<INDEXNOW_KEY>.txt` — на любом хосте.

## Переменные окружения

| Переменная | По умолчанию | Что |
|---|---|---|
| `MINIO_URL` | `http://minio:9000` | хранилище |
| `BUCKET` | `merfy-sites` | бакет; объекты — под `storefront/`, анонимное чтение |
| `RENDERER_URL` | `http://renderer:8080` | рисовальщик (блок 6) |
| `DRAW_TIMEOUT` | `5s` | сколько ждать рисовальщик |
| `ROUTES_MEMORY` | `64m` | общая память под строки таблиц; полна — 503 и запись в журнал nginx |
| `DRAW_RATE_SHOP`, `DRAW_BURST_SHOP` | `2r/s`, `10` | лимит вызовов рисовальщика на магазин |
| `DRAW_RATE_ALL`, `DRAW_BURST_ALL` | `20r/s`, `40` | лимит на всю раздачу |
| `INDEXNOW_KEY` | пусто | ключ IndexNow; уведомления шлёт сборщик (блок 6) |

Лимиты — первая оценка: их подберёт блок 6 вместе с местами и тайм-аутом рисовальщика.

## Где что

- `njs/route.js` — чистые правила: форматы объектов версии 1, ключи, ответы. Форматы меняются вместе со схемами пакета
  site-gen (`src/formats.ts`).
- `njs/serve.js` — ввод-вывод nginx: подзапросы к кэшу хранилища и к рисовальщику, общая память, ответ.
- `storefront.conf.template` — кэши, тайм-ауты, лимит и внутренний сервер вызова рисовальщика.
- `test/route.test.js` — правила; `test/serve/*.test.js` — раздача целиком; `test/fake-renderer.mjs` — подставной
  рисовальщик; `probe/probe.mjs` — проба.
- `Dockerfile` — образ раздачи, контекст сборки — эта папка.
